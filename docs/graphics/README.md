# Графическая часть РПЗ — 8 листов

Все диаграммы выполнены в нотации Mermaid (исходники `*.mmd`) и могут быть
конвертированы в PNG/SVG любой поддерживаемой утилитой (`mmdc`, расширение
для VS Code, онлайн-редактор `https://mermaid.live`). Внутри `docs/РПЗ.md`
встроены прямо как блоки ```mermaid```.

| Лист | Файл                              | Назначение                                           |
|------|-----------------------------------|------------------------------------------------------|
| 1    | `01_subject_area.mmd`             | Изображение предметной области                       |
| 2    | `02_dfd.mmd`                      | Диаграмма потоков данных (DFD)                       |
| 3    | `03_idef0.mmd`                    | Функциональная модель IDEF0                          |
| 4    | `04_er_model.mmd`                 | Инфологическая (ER) модель                           |
| 5    | `05_relational_schema.mmd`        | Датологическая (реляционная) модель                  |
| 6    | `06_system_workflow.mmd`          | Схема работы системы                                 |
| 7    | `07_structural_scheme.mmd`        | Структурная схема меню                               |
| 8    | `08_dialog_graph.mmd`             | Граф диалога                                         |

## Конвертация в PNG

```sh
npm install -g @mermaid-js/mermaid-cli
for f in docs/graphics/*.mmd; do
    mmdc -i "$f" -o "${f%.mmd}.png" -w 1920
done
```
