## Как снимать

macOS: `Cmd+Shift+4`, потом `Space`, кликнуть по нужному окну.
Полученный PNG переименовать по схеме выше и положить в эту папку.

В РПЗ §15 «Пользовательский интерфейс» каждый скриншот вставляется в порядке
их перечисления здесь, с подписью «Рисунок N — описание».
